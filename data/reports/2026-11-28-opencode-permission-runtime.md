保留原有两个项目页及其规范地址，补全相同权限问题的运行验证。原页已覆盖配置语法、版本选择和规则匹配顺序。本轮增加非交互 CLI 的写入结果验证，并调整首答与描述，避免另开一页重复覆盖相同的权限查询。

## 实测

使用先前已核验的 OpenCode 2.4.1，macOS arm64，每组使用独立临时 Git 仓库和用户配置，出站仅允许回环。模拟 Ollama 服务只发一条针对 `notes.txt` 的写入工具调用，随后返回固定回复。四组均由 CLI 实际执行，每组都读取工具事件并核对文件内容。具体规则最后匹配为 deny 时工具报权限拒绝，文件原样。泛匹配 ask 排最后时，非交互客户端无法询问，工具拒绝且文件原样。具体 allow 排最后时工具完成，实际写入内容变化。启用自动批准的 deny 对照仍被拒绝。四次进程均退出 0。

公开证据仅含合成规则、选定事件字段和文件前后内容。结果不外推至交互前端、Shell 动作、项目外路径和实际模型行为。规则和非交互客户端说明参照 [OpenCode 官方权限文档](https://opencode.ai/docs/permissions/#approvals)。保留双语原有版本决策树。新表展示固定对照结果，与版本判断入口并存。

localhost 检查两个页面在 390px 和 1440px 的首答、规范 URL、正文跳转、表格无横向溢出和证据下载。实机渲染复核后，修正章节跳转被顶栏遮挡和英文表格单词换行。
